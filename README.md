# Лабораторная работа 2. Потоковый анализатор файлов (streamstats)

Пакет `streamstats` предназначен для чтения логов событий из файлов форматов CSV и JSONL и создания сводного статистического отчета в формате JSON. Программа обрабатывает файлы построчно (без использования readlines для всего файла), что позволяет работать с логами большого размера, не переполняя оперативную память.

## Модель события
Для успешной обработки каждая строка лога должна содержать следующие поля:
* `timestamp`: дата и время в формате ISO 8601
* `level`: уровень важности лога (DEBUG, INFO, WARNING, ERROR, CRITICAL)
* `source`: источник события (непустая строка)
* `message`: текст сообщения (строка)

## Форматы входных файлов
* **CSV**: Обязательно наличие первой строки с заголовками колонок.
* **JSONL**: Каждая строка файла должна быть валидным JSON-объектом.

## Использование (CLI)
Анализатор запускается из командной строки. Поддерживается объединение статистики из нескольких входных файлов.

**Базовый запуск (строгий режим):**
```bash
python -m streamstats analyze logs.csv --format csv --output report.json
