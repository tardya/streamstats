# StreamStats

Консольное приложение на Python для потокового анализа файлов логов (CSV и JSONL) с возможностью фильтрации, обработки ошибок и генерации статистических отчетов в форматах JSON и CSV.

## Назначение проекта

Проект предназначен для выполнения следующих задач:

- потоковое чтение и анализ файлов логов (CSV с заголовком и JSONL) без полной загрузки в оперативную память;
- валидация структуры событий (проверка временных меток ISO 8601, допустимых уровней логирования, непустых источников);
- сбор статистики: общее число событий, количество событий по уровням и источникам, поиск первой и последней временной метки;
- определение топ-5 источников ошибок (уровней ERROR и CRITICAL);
- поддержка строгого режима с завершением работы при ошибках или режима пропуска битых строк (`--skip-invalid`);
- объединение статистики из нескольких входных файлов;
- ленивая фильтрация потока данных по времени, уровню и источнику;
- сохранение сводных отчетов в форматах JSON и CSV.

Запуск приложения выполняется из командной строки:

python3 -m streamstats

Для просмотра доступных команд:

python3 -m streamstats --help

## Установка и запуск

Для работы проекта требуется Python 3 (рекомендуется версия 3.10 или выше).

Сначала создаётся виртуальное окружение:

python3 -m venv .venv

После создания окружение необходимо активировать:

source .venv/bin/activate

Затем проект устанавливается в созданном окружение в режиме разработки:

python3 -m pip install -e .

После установки можно проверить доступные команды:

python3 -m streamstats --help

Для завершения работы с виртуальным окружением используется команда:

deactivate

## Структура проекта

Основной код программы находится в каталоге `src/streamstats`.

- `__main__.py` — точка запуска приложения и обработка командной строки (CLI).
- `models.py` — модель события с автоматической валидацией полей.
- `parsers.py` — потоковые парсеры для CSV и JSONL с поддержкой динамического реестра.
- `analysis.py` — класс для агрегации статистики и поиска метрик.
- `report.py` — функции для сохранения отчетов в формате JSON и CSV.
- `errors.py` — иерархия пользовательских исключений пакета.
- `__init__.py` — обозначение каталога как пакета Python.

Каталог `tests` содержит автоматические тесты для проверки всех компонентов программы.

## Использование и примеры

Приложение поддерживает команду `analyze` для обработки одного или нескольких файлов логов.

Обязательные параметры:
- `INPUT` — путь к одному или нескольким входным файлам;
- `--format` — формат входных файлов (`csv` или `jsonl`).

Пример анализа CSV-файла:

python3 -m streamstats analyze logs.csv --format csv --output report.json

Пример анализа нескольких JSONL-файлов с пропуском поврежденных строк и сохранением дополнительного CSV-отчета:

python3 -m streamstats analyze log1.jsonl log2.jsonl --format jsonl --skip-invalid --output report.json --output-csv report.csv

Пример использования ленивых фильтров (по уровню и источнику):

python3 -m streamstats analyze app.jsonl --format jsonl --level ERROR --source auth_service

## Обработка ошибок

В проекте реализована единая иерархия исключений, наследуемых от базового класса `StreamStatsError`:
- `UnsupportedFormat` — неподдерживаемый формат входного файла;
- `InvalidEvent` — неверная структура или содержимое события;
- `InvalidTimestamp` — неверный формат временной метки (нарушение стандарта ISO 8601);
- `CLIConfigError` — ошибка конфигурации параметров командной строки.

В режиме по умолчанию при обнаружении некорректной строки программа выводит информацию о номере файла и строки в `stderr` и завершает работу с кодом `2`. 
В режиме `--skip-invalid` ошибочная строка пропускается, в лог записывается предупреждение (`WARNING`), а счетчик пропущенных строк учитывается в итоговом отчете.

## Тестирование

Автоматические тесты находятся в каталоге `tests`.

Они проверяют:
- корректность работы CSV и JSONL парсеров;
- обработку пустых файлов;
- обработку поврежденных строк в строгом режиме и с флагом `--skip-invalid`;
- объединение статистики нескольких файлов;
- поддержку кодировки Unicode (кириллицы);
- интеграционную работу CLI с использованием временных каталогов.

Запуск тестов:

python3 -m pytest

Проверка кода линтером:

ruff check .
